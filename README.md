# Proyecto DWES · Juan Rivera Ordóñez

Proyecto de la asignatura **Desarrollo Web en Entorno Servidor (DWES)** del ciclo de DAW, I.E.S. Los Sauces (curso 2025-2026).

El repositorio contiene la página índice del proyecto. Desde ella se accede a los trabajos de cada unidad didáctica de la asignatura.

## Contenido

| Unidad | Tema | Contenido |
|--------|------|-----------|
| UD1 | Desarrollo web en entorno servidor | Estudio del tema 1 (PDF) |
| UD2 | Instalación, configuración y documentación del entorno | Guías de instalación del servidor (USED) y del cliente (W11ED) |
| UD3 | Características del lenguaje PHP | Enlace al proyecto del tema 3 |
| UD4 | Técnicas de acceso a datos en PHP | Enlace al proyecto del tema 4 |
| UD5 | Desarrollo de aplicaciones web | Proyecto tema 5 y aplicación LoginLogoff |
| UD6 | Aplicaciones web multicapa | En desarrollo |
| UD7 | Programación de servicios web | En desarrollo |
| UD8 | Desarrollo de aplicaciones web híbridas | En desarrollo |

## Estructura

## Tecnologías

- PHP
- HTML5 y CSS3
- JavaScript

## Despliegue

El proyecto se publica en el servidor del aula mediante SFTP. Los proyectos de cada tema (`JRODWESProyectoTema3`, `JRODWESProyectoTema4`, etc.) se encuentran en repositorios independientes y se enlazan desde este índice con rutas relativas, por lo que deben estar desplegados al mismo nivel en el servidor.
